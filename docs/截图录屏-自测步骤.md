# 截图 / 录屏 自测步骤

## 流程概览

1. **全屏模式 + 快捷键**：按截图/录屏快捷键 → App 切到「截图录屏」tab → 若有保存目录则直接执行，否则提示选目录。
2. **区域模式 + 快捷键**：按快捷键 → 切 tab → 弹出区域选择框 → 用户框选 → 松开后执行截图/录屏。
3. **按钮操作**：在截图录屏页内选「全屏」或「区域」、选保存路径后，点「区域截图」/「开始录屏」或「框选区域」再执行。

## 已实现的逻辑与防护

- 未选保存路径时：快捷键会提示「请先选择下方保存路径或选择目录」。
- 区域模式且未安装 FFmpeg：框选后会提示「请先在设置中安装 FFmpeg 后再使用区域截图/录屏」，并清除 pending，避免状态卡死。
- 区域坐标：框选时用 `clientX/clientY` × `devicePixelRatio` 转为物理像素再传给后端，与 gdigrab 一致。
- 录屏中：顶部固定条显示「录屏中 MM:SS」+「停止录屏」；截完/录完会弹出「当前截图/视频已保存至画布」及「下载」按钮。

## 建议自测用例（Tauri 桌面运行）

1. **全屏截图**  
   - 选好保存路径，模式选「全屏」，点「截图」→ 应生成一张全屏截图并弹出保存提示。

2. **区域截图（界面内）**  
   - 模式选「区域」→ 点「框选区域」→ 全屏黑罩下拖动框选 → 松开后应退出框选并得到选区；再点「区域截图」→ 应只截该区域。

3. **快捷键 + 全屏**  
   - 模式「全屏」、保存路径已选 → 按设置的截图快捷键 → 应切到截图录屏 tab 并直接截全屏。

4. **快捷键 + 区域（先弹框再截）**  
   - 模式「区域」、保存路径已选 → 按截图快捷键 → 应先切到截图录屏 tab，再自动进入全屏框选；框选完成后应自动截该区域。

5. **录屏**  
   - 点「开始录屏」→ 应出现顶部「录屏中 00:00」和「停止录屏」→ 点「停止录屏」→ 应保存视频并弹出「下载」等提示。

6. **无保存路径**  
   - 清空保存路径（或新装未选）→ 按截图快捷键 → 应提示选目录，且不执行截图。

7. **区域模式 + 未装 FFmpeg**  
   - 未安装 FFmpeg 时，选区域模式并框选 → 应提示安装 FFmpeg，且不会卡在“待执行”状态。
