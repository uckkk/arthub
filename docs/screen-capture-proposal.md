# ArtHub 截图 / 录屏方案：对比与推荐

## 一、三款开源工具简要对比

| 维度 | ShareX | Captura | OBS Studio |
|------|--------|---------|------------|
| 定位 | 全能（截图+录屏+OCR 等） | 极简录屏/截图 | 专业直播/录屏 |
| 体积 | ~10MB | 较小 | 较大 |
| 录屏核心 | FFmpeg（libx264 + CRF） | FFmpeg | 自带编码 + FFmpeg |
| 画质/体积 | CRF 18–23 视觉无损且小 | 同左 | CQP/CRF 14–23 可调 |
| 是否适合“内嵌到 ArtHub” | 否，独立完整应用 | 否，独立应用 | 否，独立应用 |

结论：三者都是**独立桌面应用**，不适合作为“一个模块”塞进 ArtHub；但它们的**技术路线**（尤其是 FFmpeg + H.264 + CRF）非常适合在 ArtHub 里**自己实现**一套短小精干的截图+录屏。

---

## 二、推荐方案：ArtHub 内置极简截图 + 录屏

不集成上述任一软件，在 ArtHub 内做**最小可用**的截图与录屏，复用现有能力，保持极简 UI。

### 1. 技术选型

| 能力 | 方案 | 说明 |
|------|------|------|
| 截图 | Rust 截图库（如 `screenshots` / `win-screenshot`）或 FFmpeg 单帧 | 全屏/区域/窗口；输出 PNG，可后续接现有图片压缩 |
| 录屏 | 复用现有 **FFmpeg**（资源管理已用） | 与 ShareX/Captura 一致：**gdigrab + libx264 + CRF**，高清且体积小 |
| 编码参数 | libx264，CRF 20–23，30fps | 与 ShareX “秘密武器”一致：视觉近乎无损、体积极小 |
| 可选 | 区域录屏（offset_x/y + video_size） | 与 Captura “仅录制区域”一致，满足极简需求 |

### 2. 为何不直接集成 ShareX/Captura/OBS

- 三者都是完整独立程序，安装包与 UI 自成一体，难以“只抠录屏一块”嵌进 ArtHub。
- ArtHub 已有 **FFmpeg 检测/下载/路径配置**（资源管理 + 缩略图），再扩展“用同一 FFmpeg 做录屏”成本低、行为一致。
- 在 ArtHub 内做“**仅：选区域 → 开始/停止 → 保存**”的 UI，更符合你要的**极简、一致**。

### 3. 实现要点（极简、可落地）

- **复用现有**  
  - 使用当前 **FFmpeg 设置**（路径、未安装时提示去设置）。  
  - UI 风格与现有 ArtHub 组件统一（深色、按钮、输入框、Toast）。

- **截图**  
  - 入口：如「全屏」「当前窗口」「区域选择」三选一。  
  - 区域选择：可用透明全屏遮罩 + 拖拽框选（与常见截图工具一致）。  
  - 输出：PNG 保存到用户选择路径（或默认“下载/桌面”）；可选接“图片压缩”做一键压缩。

- **录屏**  
  - 参数：`-f gdigrab -framerate 30 -i desktop -c:v libx264 -crf 22 -preset fast`（或 20–23 可配置）。  
  - 区域：`-offset_x -offset_y -video_size` 由前端传入选区。  
  - 流程：选择区域（或全屏）→ 点击「开始录制」→ 后端启动 FFmpeg 进程并持有句柄 → 点击「停止」→ 结束进程，输出 MP4/MKV。  
  - 可选：保存路径、CRF 在设置里可调（默认 22），不追求“专业调教”，保持默认即好用。

- **UI 极简**  
  - 一个页面/面板：顶部「截图 | 录屏」切换；截图侧：全屏/窗口/区域 + 保存路径；录屏侧：全屏/区域 + 开始/停止 + 保存路径。  
  - 所有“提醒”和“设置”入口与现有设置页、Toast 一致。

### 4. 高清且小体积（与 ShareX/Captura 一致）

- **CRF 20–23**：自动按画面复杂度分配码率，静态小、动态够清晰，满足“高清且小”的需求。  
- **preset fast**：编码速度与体积的折中，无需像 OBS 那样细调 CQP/CRF 14，默认即可。

---

## 三、结论与下一步

- **更合适的选择**：不集成 ShareX/Captura/OBS，而是**在 ArtHub 内用“Rust 截图 + 现有 FFmpeg 录屏”做一套短小精干的截图+录屏工具**。  
- **效果**：高清、小体积（与 ShareX 的 CRF 策略一致）、操作极简、UI 与现有 ArtHub 一致、复用 FFmpeg 与设置体系。  
- **建议实现顺序**：先录屏（FFmpeg 命令封装 + 开始/停止 + 选区），再截图（区域选择 + 保存）；CRF/保存路径等可放在“设置”或本页的简单选项中。

若需要，我可以再按“第一步：仅录屏（全屏 + 固定 CRF 22）”或“截图 + 录屏一起”拆成具体任务列表（后端命令 + 前端组件）。
